## Sites/Layout
### Info
This is my main link hub, found at <a href="https://doughmination.info">doughmination.info</a>

### Personal
This is my homepage for most things. You can see it at <a href="https://doughmination.gay">doughmination.gay</a>

### Fonts
This hosts all my copy of my Comic Code fonts and you can see the site at <a href="https://fonts.doughmination.co.uk">fonts.doughmination.co.uk</a>

### System
This hosts the Doughmination System API backend and frontend. The backend was originally made in Python, and the frontend in JavaScript, but later development made me migrate to TypeScript. The site is viewable at <a href="https://doughmination.co.uk">doughmination.co.uk</a>

### Mailbox
This is my <a href="https://doughmination.tech">mailbox</a>, where I receive and send emails.
